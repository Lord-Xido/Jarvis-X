Forward pass: for each axis X → Y → Z, XOR corresponding low/high bit pairs at strides 1, 2, 4, 8. Inverse pass applies the same XOR operations in reverse order. The result is exactly reversible, not inherently compressive.

      
Visual display samples at most 3,500 set voxels and auto-fits their bounds. Rendering scale is not physical storage or processing throughput.

    

  




All computation runs on this device; no server or external JavaScript library is required. The browser IDE interprets BitCube Script; the companion C++ SDK provides native execution. Snapshots are lossless but are neither encrypted nor authenticated. Memory metrics show raw active-brick payload and exclude hash-table and program overhead.
