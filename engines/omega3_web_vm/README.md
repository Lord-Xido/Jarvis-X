# JARVIS-X Ω³ Web VM v2.0

Runnable reference implementation, Python 3.10+; NumPy, PyMuPDF (inherited PDF core), SQLite with FTS5. Local CLI, not a production network service. Install `python -m pip install -r requirements.txt`.

## Run

```sh
python web_vm.py selftest --iterations 1000 --out test_output
python web_vm.py --db omega.sqlite fetch https://example.com/
python web_vm.py --db omega.sqlite query "example domain" --k 5
python web_vm.py --db omega.sqlite query "example domain" --exact
python web_vm.py --db omega.sqlite train --steps 100
python web_vm.py --db omega.sqlite verify
python web_vm.py --db omega.sqlite restore 0 recovered.html
python web_vm.py --db omega.sqlite import-html https://example.com/ saved.html
```

For web-wide discovery configure a trusted, reachable JSON search gateway (for example a compatible self-hosted metasearch service configured to allow JSON). The gateway contract is HTTP GET with `q` and `format=json`, response `{"results":[{"url":"https://example.com/"}]}`. Use your own actual endpoint, not the placeholder below. Public web providers have not been tested in this environment.

```sh
python web_vm.py --db omega.sqlite web-search "volumetric neural networks" --endpoint https://YOUR-SEARCH-HOST/search --k 5
```

The command retrieves results, explicitly downloads up to k unique result URLs, stores snapshots, and returns evidence from the entire local corpus (including previously ingested snapshots). Errors are reported individually. Evidence is normalized token text, not a generated natural-language answer. Original HTML is available via restore. Hash verifies stored bytes, not truth or authenticity. Imported URLs are caller assertions, not independently fetched provenance.

The original PDF VM is included unchanged as `pdf_core.py`. Both CLIs can use the same SQLite file, but maintain separate page address namespaces and ANN weights; no joint PDF/web ranking is implemented.

## Geometry

1,000 x 1,000 web snapshot slots, each with 1,000 base token positions; longer snapshots use explicit continuation slabs. `(x,y,z,slab)=(p//1000,p%1000,offset%1000,offset//1000)`; inverse is `(1000*x+y,1000*slab+z)`. Identical URL+hash is deduplicated; changed content occupies a new slot. Capacity is logical, not a million-page benchmark. Chunks at most 128 tokens and never cross a slab boundary. Original bytes use XOR predecessor residual + DEFLATE; semantic feature model uses signed token hashing 128 -> tanh 32 -> linear 128. FTS5 BM25 yields up to 2,048 candidates, then 0.45 latent cosine + 0.35 input cosine + 0.20 term overlap. Full scan fallback and `--exact` are available; exact refers to scanning all chunks under the implemented scoring function, not semantic truth. Training uses first 4,096 chunks, no held-out evaluation. Normal train verifies corpus and loss but does not include retrieval probes; selftest includes two fixed probes. Eight fixed opcodes are dispatched during every cycle; no arbitrary programs or self-modification. Model persisted only when candidate accepted. No LLM, visual understanding, graph traversal, JavaScript rendering, semantic pretraining, or automatic web crawling.

## Security / deployment boundaries

Run locally against trusted sources. No automatic redirects, cookies, JS execution, or linked-page crawling; 8 MiB response cap and 12-second socket timeout (not a total wall-clock deadline). UTF-8 HTML only. Private/non-global DNS results rejected, but DNS resolution is not pinned to the connection; not a hardened SSRF defense. Do not expose this fetcher to untrusted remote users. For production use a network-isolated, allowlisted fetch proxy, robust time/rate limits, robots/terms compliance, bounded decompression, protected storage, and independent integrity manifests. Search results and restored HTML are untrusted; opening restored pages in a browser may execute their original scripts. The test fixture's localhost exception is not exposed by the CLI. URLs, content and timestamps stored in the same DB do not provide independent tamper evidence. Search quality and scalability require representative corpus tests. 

## Verification artifacts

`test_output/summary.json`, `trace.jsonl`, `program.bin`, `web.sqlite`, `self.html` are generated by the actual 1000-cycle test. Local HTTP service provided four fixture pages and a JSON search endpoint; the fixture URL port and timestamp are test metadata, not live public-web observations. Self HTML stores both source files as base64 and verifies exact byte recovery. Fault injected in cycle 500, rejected; checks also cover restart, address continuation, index integrity, stored digest corruption, private host/redirect rejection, retrieval probes in both scan and FTS modes initially. Test fixture endpoint is not running after test. The model is not a self-rewriting quine.
