# Inward Recursive 3D Auto-Optimization ROM Engine

Status: research reference profile

This directory turns the proposed DM–vΩΞ⁺ inward-fold ROM into a bounded, testable fixed-point microkernel compatible with the accepted ADR-009 register/word model:

```text
[ opcode:8 ][ dest:4 ][ src1:4 ][ src2:4 ][ immediate/sub-op:12 ]
```

The reference keeps the 16-register constraint, saturating signed Q16.16 arithmetic, and widened multiply semantics. It does **not** redefine the canonical Jarvis-X VM and does not claim that a WebGPU or native compiler necessarily lowers the source to branch-free machine code without inspection.

## Corrected objective

The original one-pass draft overwrote the input, computed an unsigned gap, adjusted a weight only downward, produced a convergence mask that was never consumed, and unconditionally halted. That can collapse toward a trivial state and cannot establish recursive convergence.

The perfected kernel uses an immutable focused anchor:

```text
A = LENS * X_0
```

and a recurrent state `X_k` with a rank-1 tied-weight autoencoder:

```text
a_k      = W_k^T X_k
z_k      = ReLU(a_k)
Xhat_k   = W_k z_k
e_k      = Xhat_k - A
gamma_k  = ||e_k||_1
```

The optimization loss is therefore anchored to the original focused observation rather than a moving reconstruction target.

For positive activation, the exact tied-weight gradient of

```text
L_k = 0.5 * ||W_k ReLU(W_k^T X_k) - A||_2^2
```

is

```text
g_j = e_j z + (sum_i e_i w_i) * ReLU'(a) * x_j
```

with `ReLU'(0)=0` by contract. The update is

```text
W_candidate = W - eta * g
```

where `eta = 1/16` in Q16.16.

To preserve inward recurrence without allowing the recurrent input to collapse away from the immutable anchor, the next state is an anchored relaxation:

```text
X_candidate = A + rho * (Xhat - A)
```

with `rho = 1/4`.

## Branchless fixed-point lock

Convergence is evaluated against a configurable Q16.16 tolerance:

```text
gamma <= EPS
```

The default is 64 raw Q16.16 LSBs (`0x00000040`, about `9.77e-4`). The candidate lock mask is generated by subtracting `EPS + 1` and extracting the sign bit, so equality is included.

The lock is sticky:

```text
LOCK_next = LOCK | converged_mask
```

and every state/weight update is selected arithmetically:

```text
next = (old & LOCK_next) | (candidate & ~LOCK_next)
```

Once convergence is observed, subsequent passes preserve the exact locked state.

## Bounded recursion

The ROM source contains no data-dependent branch. Instead, the pass body is expanded a fixed `K = 192` times by the assembler macro layer:

```text
.REPT 192
    INWARD_PASS
.ENDR
HALT
```

This gives deterministic work and termination. Convergence changes data through masks; it does not change control flow.

The fixed-point claim is therefore restricted to the validated discrete condition:

```text
gamma_k <= EPS
```

not an assertion of universal or unique convergence for arbitrary inputs and weights.

## Register map

```text
R0-R2   recurrent focused state X_k/Y_k/Z_k
R3      latent scalar z
R4      typed weight-base pointer
R5      typed state/scratch-base pointer
R6      arithmetic scratch / signed residual
R7      eta = 0x00001000 (1/16)
R8-R10  reconstruction Xhat/Yhat/Zhat
R11     coupling accumulator / arithmetic scratch
R12     latent accumulator / gap / candidate scratch
R13     rho = 0x00004000 (1/4)
R14     sticky lock mask (0 or 0xFFFFFFFF)
R15     lens during initialization; reusable scratch after anchor creation
```

## Q16.16 rules

- storage: signed 32-bit;
- scale: `2^16`;
- add/subtract: saturating;
- multiply: widened signed product, arithmetic shift right by 16, then saturate;
- absolute value: `INT32_MIN` saturates to `INT32_MAX`;
- all persistent weights/state are finite signed Q16.16 values;
- pointers/control masks are typed 32-bit values and are not interpreted as Q16.16.

## Memory contract under R5

```text
0x000..0x008   W0/W1/W2
0x020..0x028   immutable focused anchor A0/A1/A2
0x040..0x048   signed residual E0/E1/E2
0x04C          final/current gamma
0x050          sticky lock mask
0x054          ReLU derivative mask
0x058          unlocked mask
0x100..0x108   committed X/Y/Z
0x10C          committed latent z
0x110          committed gamma
0x114          committed lock mask
```

The anchor region is write-once after initialization for the duration of a run.

## Files

- `inward_recursive_rom.asm` — perfected branchless ROM macro-source.
- `reference.py` — executable bit-level Q16.16 reference model.
- `test_inward_recursive_rom.py` — conformance and fixed-point regression tests.

## WebGPU lowering boundary

A WebGPU implementation may implement the same state transition, but it is only bit-exact if its Q16.16 multiply reproduces the widened-product contract above and its buffer update ordering preserves the same pass semantics. Shader source, browser compilation, and GPU execution are separate lowering layers and must be profiled/validated before making hardware-level branchlessness or latency claims.
