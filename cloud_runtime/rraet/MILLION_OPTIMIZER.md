# RRAET stationary geometric optimizer v2 — bounded reference

This native C++17 reference is a numerical experiment, not an implementation of a trained ANN or a deployed cloud engine. It complements rather than replaces the lagged-history RRAET engine. Its known-source synthetic observation is Y=HX*, H=10I+A, with A the six-neighbor periodic adjacency. Byte-valued source is generated by a deterministic SplitMix64 seed 42.

Each candidate shifts an aligned 1³, 2³ or 4³ block by an integer delta. If r=Y-HX and v=H indicator(block), the exact squared loss change is delta²(v·v)-2 delta(r·v). Choose the nearest feasible integer to (r·v)/(v·v), evaluate affected residuals independently, and accept only strict improvement. Every 250,000th proposal uses a full-field fixed-point Jacobi shadow candidate (32 sweeps, scale 65536), rounded to bytes, with the same objective gate. The real projected Jacobi map contracts in infinity norm by 0.6; fixed-point rounding introduces a bounded perturbation. H is invertible by strict diagonal dominance. Exact observation equality implies exact source recovery for this fixture.

Recompute forward and loss after every accepted update and each 1,000th proposal. Store every decision, including rejection, in CSV. FNV is a noncryptographic deterministic replay fingerprint, not authenticated evidence. The global rescue candidate's trace uses scale=0 and coordinate sentinel -1; reconstruction of the candidate requires deterministic replay. Full proposals count includes four global rescue candidates (each consists of 32 sweeps). A rejected zero shift is possible when all block values admit no common nonzero shift.

## Reproduce

```sh
g++ -std=c++17 -O3 -Wall -Wextra -Wpedantic -Wconversion -Wshadow -Werror cloud_runtime/rraet/million_optimizer.cpp -o rraet
./rraet 16 1000000 trace16.csv
./rraet 8 1000000 trace8.csv
./rraet 4 1000000 trace4.csv
```

Local verification: all three sizes reached zero SSE and zero source errors; 16³ replay was byte-identical. Prior local-only search stalled at SSE 4008 (8³) and 1024 (4³), motivating global rescue. The optimized version achieved first zero at 194186 (16³) and 250000 (8³, 4³). No claim is made that this is faster than a direct Jacobi solve, generalizes to noisy or ill-conditioned inverse problems, or proves system-wide convergence. The source is a standalone reference; future adapter work must conform to ADR-016/017 and integrate with the packaged API. No network transport or GPU acceleration is provided.
