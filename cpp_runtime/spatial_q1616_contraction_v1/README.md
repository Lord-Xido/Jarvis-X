# Jarvis-X deterministic 3D Q16.16 contraction reference (v1)

Isolated **C++17 reference module** derived from a 1,000,000-point fixed-point example. No existing Jarvis-X APIs or files need to change.

## Execute

```sh
cmake -S cpp_runtime/spatial_q1616_contraction_v1 -B /tmp/jx-spatial-build -DCMAKE_BUILD_TYPE=Release
cmake --build /tmp/jx-spatial-build -j2
ctest --test-dir /tmp/jx-spatial-build --output-on-failure
/tmp/jx-spatial-build/spatial3d_demo --count=1000000 --steps=1 --scale=0.5
```

## Semantics

- 1,000,000 unique **regularly indexed but spatially separated** 3D points; axis coordinates are 1.5, 2.5, 3.5 times an index in [1, 100]. This is *not* an octree or compressed sparse voxel field.
- 3 components per point stored as Q16.16 signed 32-bit integers, approximately 12 MB of coordinate payload (excluding vector overhead). Valid Q16.16 magnitude is less than 32768. The original code's linear index multipliers exceed Q16.16 range for most of 1M points; this version bounds all coordinates.
- Lambda scale must be in [0,1). Quantization by truncation toward zero is explicit. Each candidate update is committed atomically only after all points have been transformed.
- Default 0.5 contraction: first point (1.5,2.5,3.5) becomes (0.75,1.25,1.75); last (150,250,350) becomes (75,125,175).
- Deterministic FNV-1a digest for sanity/reproducibility, **not** a tamper-proof cryptographic audit.
- Float/double are used only for scale API and presentation; the coordinate loop is int32/int64 fixed point.
- Continuous map p -> lambda*p is contractive in a norm for 0<=lambda<1. On a discretized Q16.16 lattice, exact strict Banach contraction is not established for every adjacent pair. No exact inverse of the lossy contraction is claimed.
- Not a learned ANN autoencoder, a generalized sparse voxel map, or a photorealistic renderer. No cloud or production deployment.

## Geometry

Coordinates are generated by mapping a flat index `i` to `(i%100, (i/100)%100, i/10000)` plus 1 in every dimension. It is an XYZ grid in a larger continuous domain, **not** a million independent parameterized neural layers. The original `print_first_point` inspected the origin, masking any scale change; this module prints the first and last nonzero points with a state fingerprint.
