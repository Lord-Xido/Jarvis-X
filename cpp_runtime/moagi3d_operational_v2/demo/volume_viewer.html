Moagi3D · Deterministic Volumetric Field

Actual C++ v2.0 demo data · 16 × 16 × 16 voxels · drag to rotate · scroll to zoom · offline

The visualization plots two arrays exported by the native C++ runtime. It does not implement native encoding in the browser. Values are Q0.16 integers between 0 and 65535. This field is a deterministic spatial statistic, not trained AI inference. Archive round-trip validity is established by the native decoder and test suite, not this visualization.
