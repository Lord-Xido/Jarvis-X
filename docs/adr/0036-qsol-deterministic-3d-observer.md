# ADR-0036: QSOL read-only 3D reverberation and deterministic observation

- **Status:** Proposed with C++17 reference implementation
- **Date:** 2026-10-10
- **Scope:** Existing 80,000-pixel inward graphics ANN target (ADR-0035)
- **Files:** `cpp_runtime/src/qsol_reverberation3d.hpp`, `cpp_runtime/src/inward_graphics_ann_main.cpp`

## Decision

The existing renderer/ANN remains authoritative for its own transactional state.
Add a **separate**, normalized `16^3` Q16.16 reverberation field and a
read-only `256`-component observation/visualization projection. The observer
has no reference, pointer or command channel capable of modifying that field,
the ANN weights, or the rendered framebuffer.

The frame is the existing **400 x 200 = 80,000 pixels**. The input adapter
samples 4,096 RGB pixels at deterministic linear indices
`floor(k*80000/4096)`. For each pixel:

```
u[k] = trunc_toward_zero((int(red) - int(blue)) * 65536 / 255)
```

No 80,000 x 80,000 or 80,000^3 physical allocation is implied.

## Stable 3D state evolution

Let `P` be the periodic six-neighbour **mean** on `Z_16^3`:

```
x[t+1] = A x[t] + B u[t]
A      = (3/4) I + (3/16) P
B      = (1/16) I
||P||_infinity = 1
||A||_infinity <= 15/16 = 0.9375
```

All state and forcing components are normalized to `[-1,1]`. In Q16.16
integer arithmetic the *single-division* update for each voxel is:

```
next[k] = trunc_toward_zero(
    (72*x[k] + 3*sum(six_neighbor_x) + 6*u[k]) / 96
)
```

Integer calculations use signed 64-bit accumulators before division, then
validate each output against `[-65536,65536]`. The exact-integer recurrence
adds quantization, so the real-valued norm bound is not a claim of exact
exponential decay to zero at sub-LSB scales. The integer implementation is
bounded and deterministic for identical Q16.16 inputs.

## Non-mutating observation

Non-overlapping `2 x 2 x 4` voxel regions form `8 x 8 x 4 = 256` observer
components. Each is:

```
y[j] = trunc_toward_zero((3*sum(x in region_j) + sum(u in region_j)) / 64)
```

Thus `y = (3 C x + C u) / 4` before integer quantization. The observer
takes only `const Field&` values and returns its own `Observation` value.
No observer field is fed to the authoritative state recurrence or ANN update.

Mathematical authority rule: `d x[t+1] / d y[t] = 0` for the QSOL state
transition **when external forcing is held fixed**. This does not prohibit
separately authorized ANN candidate updates using the existing CTR verifier.

## Deterministic hash contract

Each signed Q16.16 observation value is converted modulo 2^32 to `uint32`.
Its four bytes are fed into a 64-bit FNV-1a recurrence in explicit
**little-endian** order. The uint32 frame index is hashed last.
No floating-point random generator, unstable object serialization, wall clock,
or GPU state enters the QSOL hash.

```
hash64 = FNV1a64(LE32(y[0]) || ... || LE32(y[255]) || LE32(frame))
dx     = (hash64 mod 13) - 6
dy     = ((hash64 >> 16) mod 13) - 6
```

`dx` and `dy` are reproducible *integer layout telemetry*, not a claim that
all GPU rasterizers produce bit-identical images. Input pixels generated by
floating-point drawing functions can still differ across platforms. Therefore
the hash is identical for identical quantized input streams; no unconditional
cross-device pixel-identity claim is made.

The JSON receipt exports `qsol_voxels`, `qsol_observer_units`,
`qsol_contraction_bound`, `qsol_state_hash`, `qsol_render_hash`,
`qsol_camera_dx`, and `qsol_camera_dy`. Hashes are emitted as decimal
**strings** to prevent JavaScript 64-bit precision loss. Hash telemetry does
not control the existing renderer, learning rate, or candidate admission.

For reproducible headless experiments, simulation time uses the fixed index
`t = frame * 0.025`; the on-screen terminal mode remains real-time.

## Verification and execution

```bash
cmake -S cpp_runtime -B build/qsol -DCMAKE_BUILD_TYPE=Release -DJARVISX_BUILD_GL_VISUALIZER=OFF
cmake --build build/qsol --target jarvisx-80k-pixel-inward-ann
build/qsol/DrMoagi-80K-Pixel-Inward-ANN --self-test
build/qsol/DrMoagi-80K-Pixel-Inward-ANN --headless --frames 30 --json

c++ -std=c++17 -O2 -Wall -Wextra -pedantic -Icpp_runtime/src \
  cpp_runtime/tests/qsol_reverberation3d_test.cpp -o qsol-test
./qsol-test
```

The tests cover periodic adjacency, 256 observer units, pure observation,
repeatable frame-hash output, range validation, bounded forced response,
unforced decay toward quantization zero, and constant-field known-answer
vectors. The existing 80K C++ regression, CTR commit gate, and sanitizer
workflow remain in place.

**Evidence boundary:** this is a software reference for a stable recurrence
and a non-mutating observer. It is not a hardware chip, universal AGI, or proof
of byte-identical rasterization across differing GPUs.
