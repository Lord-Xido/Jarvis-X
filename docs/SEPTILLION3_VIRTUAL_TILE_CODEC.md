# DM3D septillion³ virtual autoencoding/decoding contract

## Scope

This feature adds the exact RGB8, spatially addressable, browser/Node reference tile codec. It complements the existing Jarvis-X sparse bitstream and swarm research engines; it does not replace their code, modify live control planes, or increase allocated memory to astronomical size.

Let `S=10^24` and `Lambda=(Z/SZ)^3`, so `|Lambda|=10^72` *logical* positions. The linear address `i=x + S(y + Sz)` is unique for `0 <= x,y,z < S`. The field generator is deterministic, but it encodes only a restricted procedural family—not arbitrary independent `10^72` RGB values.

A local tile starts at `8q`, where `q in [0,S/8)^3`. The hashed seed and **full decimal coordinates** drive the RGB values so JavaScript numbers never approximate the virtual address. SHA-256 here is applied to real finite tile bytes, not to the astronomical logical field.

## Operational equations

```
X_q    = F_seed(8q + r)               r in {0,...,7}^3
Z_q    = round(MeanPool_2(X_q))       Z_q in uint8[4,4,4,3]
Z_q^*  = Phi_T3^K(Z_q)                periodic 6-neighbour mixing on 4^3 tile
Xhat_q = Repeat_2(Z_q^*)             uint8[8,8,8,3]
R_q    = (X_q - Xhat_q) mod 256
X_q    = (Xhat_q + R_q) mod 256       bit-exact reconstruction
```

For each channel at lattice site `p`, `Phi(z)[p] = round((1-alpha)*z[p] + alpha/6*sum_{six periodic neighbours}z[q])`. `0<=alpha<=1`, `0<=K<=100`. This stencil is **tile-local** and should not be misinterpreted as global coupling among `10^72` sites.

The browser's feedback routine measures mean squared error on a finite tile set and only accepts alpha candidates yielding strictly smaller measured loss. Validation used to *select* alpha is not an independent post-selection evaluation.

## Checks and authority boundary

Run `node apps/septillion3-virtual/test_cross_language.js`. Coverage includes arbitrary-precision coordinate boundaries, field determinism, 3 far-separated reference tile SHA-256 values generated by the original Python implementation, approximate MSE parity, exact modulo-256 byte reconstruction, corrupted-byte hash mismatch, stencil constant invariance, and a non-worsening scalar selection example.

**Binary packet limitation:** Node and browser test the restoration algorithm; this version does not export the earlier Python zlib/Base64 packet format. The prior archive remains a standalone reference until a packet serializer is ported into the repository. Neither the virtual byte count nor the pooled latent bytes alone is a measured compression ratio; include residual and metadata costs.

This is a deterministic codec emulator, not a trained multimodal ANN, AGI, physically materialized global tensor, or GPU benchmark.
