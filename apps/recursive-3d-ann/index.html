Representation ≠ hardware parallelism ≠ language intelligence. This model performs genuine 3D convolutional encoding and decoding, but uses a small synthetic vocabulary and a 1-token-context generator. Measured rates do not generalize to large language models.
Runtime: trained PyTorch weights exported to this self-contained HTML, with JavaScript reference inference for the ANN and spatial convolutional autoencoder. Input token values are discrete categorical IDs; all coordinates are actual tensor indices. 3D projection is a visualization of those computational arrays. The exact-recovery residual is stored separately; no compression advantage is claimed.
