Operational mathematics

F(X) = D(M(E(X))) with 3D periodic boundary conditions. Here R in the canonical expression is identity.

E: average every adjacent 2×2×2 voxel block into one latent value. M: diffuse every latent value towards its six orthogonal latent neighbours. D: expand each latent value back to a 2×2×2 block. Repeat until stable.

M(z)ᵢ = (1−α)zᵢ + (α/6)Σⱼ∈N₆(i) zⱼ, α=0.25

Limit: over many iterations the entire field approaches its global mean. This proves stability for this test but progressively destroys spatial detail.

Original artifact audit boundary

  • Original code: 1,000 particle state objects; 10,000 and 100,000 rendered background points.
  • Original phase sequence: INPUT → ENCODING → LATENT → DECODING → OUTPUT, without numerical encoder/decoder tensors.
  • Original reported compression is a formula based on simulated loss; no serialized latent payload.
  • Original rates count phase events in a 30-frame interval, rather than timing bytes processed.
  • This verifier substitutes actual arrays, deterministic numerical operators, a measured serialization size, and repeatable fixed-point tests.
