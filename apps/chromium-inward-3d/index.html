Model scope
Bounded HTML/CSS, block layout, display lists, adaptive RGBA tiles, frame aggregation, two buffers and exact pixel verification. A finite controller tests rendering policies on this document's headings, scrolling and repeated frames. It minimises counted drawing calls, then stage executions. Those counters are not a speed estimate; probe timing and tuning overhead are reported separately.
The feedback packets contract in real 3D coordinates toward the controller core. Ω retains a moving average of observed work and pixel residuals. Accepted policies survive reload where local storage is available. Each pass stops at a verified fixed policy or its probe budget. The logical 1024³ cube uses sparse working data; no billion-cell array is allocated.
