What the geometry means

The grid maps the active window to a 256 × 256 × 32 lattice. Each rendered cube samples one exact byte address. Size tracks set bits; nebula radius uses nine bit-count shells. Emerald marks addresses below 8,192, slate is 00, pink is FF and cyan covers other values.

Entropy is the empirical single-byte Shannon entropy of this window. Encoded sizes include the 16-byte transport header. FPS is measured locally. No full-space entropy or hardware throughput is inferred.
